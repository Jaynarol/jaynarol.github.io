# สร้างบล็อกด้วย Astro

Astro เป็น framework ที่ยอดเยี่ยมสำหรับการสร้าง static sites

## ทำไมต้อง Astro?

1. **Performance**: เร็วกว่าเพราะเป็น static site
2. **SEO Friendly**: เหมาะสำหรับบล็อก
3. **Developer Experience**: ใช้งานง่าย

## ฟีเจอร์ที่ใช้

- Content Collections
- Markdown Support
- Tailwind CSS
- TypeScript
