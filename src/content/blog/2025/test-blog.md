# ทดสอบบล็อกใหม่

นี่คือบล็อกทดสอบเพื่อดู URL structure แบบใหม่

URL ของบล็อกนี้ควรจะเป็น: `/blog/2025/test-blog`

## การจัดเก็บไฟล์

- ไฟล์นี้อยู่ที่: `src/content/blog/2025/test-blog.md`
- URL slug จะเป็น: `2025/test-blog`
- URL เต็มจะเป็น: `/blog/2025/test-blog`
