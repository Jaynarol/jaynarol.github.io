สร้างบล็อกฟรีด้วย Astro + GitHub Pages

20 มิถุนายน 2025 • 4 months ago

สวัสดีชาวโลก! ประเดิมมีบล็อกแรกด้วยคำถามที่น่าสนใจครับ ทำไมต้องเลือก Astro และ GitHub Pages ??

ทำไมถึงเลือก Astro?

ปกติผมแฟน React และ Next.js นะครับ หลังจากที่ลองเครื่องมือสร้างเว็บหลายตัว ก็ตกหลุมรัก Astro เพราะ:

  • กระทัดลัด - client โหลดเร็วมากเพราะมี js เท่าที่จำเป็นจริงๆเท่านั้น
  • เข้าใจง่าย - framework ไม่มีความซับซ้อน ออกแบบมาตรงจุดสำหรับ web content
  • ทรงพลัง - แทบไม่ต้องปรับแต่งอะไรเยอะก็เริ่มเขียน Markdown ได้เลย

อ่านรายละเอียดเพิ่มเติมได้ที่ เว็บไซต์ Astro

// ตัวอย่าง Astro component
---
const title = "Hello Astro!";
const currentDate = new Date();
---

<h1>{title}</h1>
<p>วันที่: {currentDate.toLocaleDateString('th-TH')}</p>

GitHub Pages = โฮสต์ฟรีตลอดชีวิต

ที่สำคัญคือ GitHub Pages ให้เราโฮสต์เว็บฟรี! แค่:

  1. สร้าง repository บน GitHub
  2. ตั้งค่า GitHub Pages ให้มาอ่านโฟเดอร์ docs เป็น root
  3. Push code แล้วเว็บจะอัปเดทอัตโนมัติ

ฟรี + ไม่ต้องกังวลเรื่องค่าโฮสต์ = สบายใจสบายกระเป๋า 💰

ทำไมถึงเลือกเขียนบล็อก?

ผมเป็นคนชอบโน๊ต ชอบบันทึกสิ่งต่างๆ ที่เรียนรู้มา การมีบล็อกส่วนตัวเลยเป็นเหมือนมีคลังข้อมูลส่วนตัวที่:

  • เก็บความรู้ไว้ดูย้อนหลังได้
  • แบ่งปันประสบการณ์ให้คนอื่น
  • บังคับให้เราเรียนรู้และทำความเข้าใจลึกขึ้น
  • ค้นหาความรู้เก่าๆง่ายๆ

สิ่งที่จะมาต่อ

จะพยายามเข้ามาอัพเดทเรื่อยๆสำหรับความรู้ความเข้าใจที่ผมคิดว่าสำคัญและมีประโยชน์ เช่น:

  • การพัฒนาเว็บ และเทคโนโลยีต่างๆ
  • ประสบการณ์การเรียนรู้สิ่งใหม่ๆ
  • ธรรมะและการปฏิบัติ (ตามความเข้าใจของผม)
  • และอื่นๆ ที่น่าสนใจ

หวังว่าจะเป็นประโยชน์กับทุกคนที่แวะมาอ่านนะครับ ขอบคุณครับ! 🙏

P.S. ถ้าใครสนใจโค้ดของบล็อกนี้ สามารถดูได้ที่ GitHub repo ของผมเลยครับ

บทความแนะนำ

ค้นพบบทความอื่นๆ ที่น่าสนใจและอาจเป็นประโยชน์สำหรับคุณ
